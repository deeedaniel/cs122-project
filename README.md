# CS 122 Project: Amazon Product Analysis

## Collaborators
- Daniel Nguyen
- Nyi Htet

## Overview
Amazon Product Analysis is an interactive web application designed to help users identify trending products and evaluate potential selling opportunities on Amazon. The application analyzes product and sales-related metrics across selected categories to help users make data-driven decisions about which products may be worth selling.

## Features
- **Product Analysis:** Explore product information across selected Amazon categories.
- **Trend Identification:** Analyze product metrics to identify potentially trending products.
- **Profitability Analysis:** Evaluate available pricing and sales metrics to assess potential selling opportunities.
- **Data Visualization:** Use charts to explore relationships and patterns in product data.

## Technologies
- **Python** — Data processing and analysis
- **Pandas** — Data manipulation
- **Numpy, Scipy, Seaborn** — Statistical data visualization
- **Matplotlib** — Chart rendering
- **Web Framework:** To be determined

## Objective
The goal of this project is to apply data analysis and visualization techniques to e-commerce product data, helping users better understand product trends and potential selling opportunities.
